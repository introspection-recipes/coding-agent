# Starter Template

A starter template for Pi.

[![Use this template](https://img.shields.io/badge/Use_this_template-181717?style=for-the-badge&logo=github)](https://github.com/new?template_name=pi-starter&template_owner=introspection-recipes)

## Quick Start

Create a repository with the button above, open it locally, then run:

```bash
pi install npm:@introspection-ai/recipes
cd your-repository
pi --recipe .
```

## What's Included

- A ready-to-run Pi agent
- Shared behavior in `SYSTEM.md`
- Model, tools, skills, and subagents in `agents/agent.yaml`

[Read the Recipes documentation →](https://pi.recipes/docs)
